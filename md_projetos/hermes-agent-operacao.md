# Hermes Agent & IA Aplicada à Operação de TI

## Configuração, Automação e Suporte Assistido com Agentes de IA

### Visão Geral
Implementação prática de Inteligência Artificial para operação assistida de infraestrutura de TI, utilizando agentes especializados como **Hermes Agent**, **OpenCode**, **Codex/Codebuff** e **GitHub Copilot** para diagnosticar incidentes, corrigir sistemas legados, documentar ambientes e acelerar melhorias com controle técnico rigoroso.

### Tecnologias Utilizadas
- **Hermes Agent** (Nous Research) — agente autônomo multi-ferramenta
- **OpenCode / Codex** — agentes de codificação assistida
- **GitHub Copilot** — assistente de programação
- **Provedores LLM**: Groq, Gemini, OpenRouter, modelos gratuitos
- **Laravel/PHP Legacy**, Apache, PHP-FPM, Linux

### Funcionalidades Principais
- Diagnóstico automatizado de falhas em aplicações Laravel/PHP legadas
- Correção assistida de código com revisão humana
- Configuração de fallback entre provedores de modelos
- Compactação de contexto para sessões longas
- Guardrails para leitura antes de edição (segurança operacional)
- Auditoria de histórico de sessões e modelos utilizados

### Resultados
- Agilidade significativa na correção de bugs em sistemas legados
- Documentação precisa de ambientes complexos (mapeamento de servidores, aplicações e dependências)
- Padronização de mudanças com checklist de verificação pré e pós-alteração
- Redução do tempo de diagnóstico com análise contextualizada de logs
